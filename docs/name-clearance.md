# Knights — Preliminary Name Clearance

> **⚠️ NOT LEGAL ADVICE.** Best-effort desk research from public web sources. Authoritative
> registries (USPTO, EUIPO, UK IPO) and WHOIS were **blocked by the environment's proxy**, so the
> trademark/domain specifics are **inference-based (medium/low confidence)** — leads to verify, not
> conclusions. Commission a **formal clearance from a trademark attorney** (Classes 25 clothing / 18
> leather / 35 retail; USPTO + EUIPO/UKIPO) before committing money to branding, inventory, or filings.

## Verdict
**Bare, one-word "KNIGHTS" is high-risk for a premium menswear/leather brand — advise against it.**
Two problems stack: a crowded clothing trademark class already anchored by a large same-name
incumbent, and no clean, affordable exact-match domain. A **distinctive qualifier or coined form**
solves both at once.

## 1. Existing "Knights" brands (apparel/leather)
- **Knights Apparel** (now **HanesBrands**, ~$200M acquisition, 2015) — licensed collegiate/sports
  apparel, Class 25. **Biggest flag:** same name, same class, well-resourced owner with incentive to oppose.
- **British Knights** — live US + EU marks (footwear/apparel).
- **KNIGHT** (word+crest, German owner) — live US Class 25.
- **Black Knights** (US Army) — live Class 25.
- **Knighthood**, **Knightsbridge**, **Knights Menswear (MN)** — menswear/leather using knight imagery (different names / common-law).
- Heavy sports-team apparel (Vegas Golden Knights, UCF, etc.) further crowds "Knights on a jacket."

## 2. Trademark (Class 25) — medium confidence
Class 25 is the most crowded class; with live KNIGHT / BRITISH KNIGHTS / KNIGHTS APPAREL / BLACK
KNIGHTS marks, a bare "KNIGHTS" application is a realistic target for a likelihood-of-confusion
refusal or opposition — and even if it registered, it'd be a **thin, hard-to-enforce** mark
(common dictionary word). Classes 18/35 need their own searches (expect similar crowding).

## 3. Domains — medium confidence (DNS-inference, not WHOIS)
- `knights.com` — **taken** (premium one-word .com; 6–7 figures if sellable at all).
- `knights.co`, `theknights.com`, `knightsleather.com` — appear **taken**.
- Left over for bare "Knights": awkward add-ons (`wearknights`, `knights-official`) or
  registry-premium new-gTLDs (`.store/.shop/.clothing`). **No clean flagship domain.**
